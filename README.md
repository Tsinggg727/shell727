# SHELL—727 · 郭洁颖的个人主页

纯静态个人网站：无框架、无构建步骤、无后端依赖，全部逻辑在浏览器本地运行。

## 文件结构

```
├── index.html          # 唯一入口（hash 路由：#/home #/profile #/wall #/quiz，未知地址 → 404 页）
├── styles.css          # 全部样式（含移动端适配）
├── app.js              # 全部交互逻辑
└── assets/
    ├── shell727-cut.webp   # 寄居蟹形象（吉祥物）
    ├── favicon.svg
    └── patterns/           # 可选背景纹样（默认关闭，?pat=a 开启）
```

## 本地预览

任选其一：

```bash
# Python
python -m http.server 8127
# 或 Node
npx serve .
```

然后访问 `http://127.0.0.1:8127`。（直接双击 index.html 用 file:// 打开也能看，但留言的本地保存等特性在部分浏览器会受限，建议起本地服务。）

## 部署方法

整个文件夹就是部署产物，把**文件夹里的内容**（不是外层目录）上传到任意静态托管即可：

- **GitHub Pages（当前使用）**
  1. 仓库：`github.com/Tsinggg727/shell727`（本文件夹即仓库根，git push 即发布）；
  2. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)`；
  3. 访问 `https://tsinggg727.github.io/shell727/`。
- **PythonAnywhere（当前使用）**：挂在 ConfTrends 旁边的子路径
  `https://tsinggg.pythonanywhere.com/727/`，步骤见《PythonAnywhere部署说明.md》。
- **Vercel / Netlify / Cloudflare Pages**：导入仓库或直接拖拽文件夹上传，零配置。
- 注意：文件全部使用相对路径，部署在子目录也能正常工作；`server.js` 与两份部署
  说明只在自建服务器时用到，静态托管带上也无害。
- **留言**：静态托管（GitHub Pages / PythonAnywhere 子路径）下留言只存访客本地
  （localStorage）；要服务器接收留言需跑 `server.js`（见《后端部署说明.md》）并设置
  `app.js` 顶部 `MESSAGE_API`。
